# Sosial siyasət – Adam asmaca

Mövzu 3 (sosial siyasət) slaydlarındakı terminlər əsasında hazırlanmış adam asmaca oyunu.

- 30 termin və ipucu
- 4 obraz seçimi (Leyla, Rəşad, Robo, Pişik) – 3D təsirli vektor obrazlar
- Hər yanlış cavabda obrazın bir hissəsi təsvir olunur (6 can)
- Azərbaycan əlifbası, ekran və fiziki klaviatura dəstəyi
- Tək fayldır (`index.html`), əlavə kitabxana tələb etmir

## GitHub Pages ilə yayımlamaq

1. Yeni repozitoriya yaradın və `index.html` ilə `README.md` fayllarını yükləyin.
2. **Settings → Pages** bölməsinə keçin.
3. **Source** olaraq `Deploy from a branch`, branch olaraq `main` və qovluq olaraq `/ (root)` seçin.
4. Bir neçə dəqiqə sonra oyun `https://<istifadəçi-adı>.github.io/<repo-adı>/` ünvanında açılacaq.

## Lokal açmaq

`index.html` faylını brauzerdə açmaq kifayətdir.
